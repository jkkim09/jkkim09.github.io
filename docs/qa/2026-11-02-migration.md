# 포트폴리오 마이그레이션 검증

검증일: 2026-11-02 (Asia/Seoul)

## 적용 범위

- React 19.3.1, Vite 8.3.5, TypeScript 6.0.3, Tailwind CSS 4.3.3, Prettier 3.9.10.
- 앱·설정·배포 스크립트를 `.ts`·`.tsx`로 전환. Sass와 CRA, Material UI/Emotion 제거.
- `projects.ts`의 데이터를 EXPERIENCE, TIMELINE, 이력서에서 공유.
- EXPERIENCE와 TIMELINE은 `ProjectContent.tsx`로 제목·기간·부가 설명·기술·상세 업무를 동일하게 표시.
- `cn()`은 `clsx`와 `extendTailwindMerge`를 사용. Prettier가 `cn()` 내부 클래스도 정렬.
- `카카오 뱅크`: 2026-02-11부터 2027-02-28까지 종일 일정. 기존 일정 6개 유지.

## 자동 검사

`npm run check` 통과:

| 검사                     | 결과                                                      |
| ------------------------ | --------------------------------------------------------- |
| Prettier                 | 전체 대상 파일 통과                                       |
| ESLint                   | 경고·오류 없음                                            |
| Vitest                   | 4개 파일, 16개 테스트 통과                                |
| TypeScript               | 앱·테스트·설정·배포 스크립트 통과                         |
| Vite 프로덕션 빌드       | 통과                                                      |
| GitHub Pages 산출물 검증 | 빌드와 루트 산출물 일치, manifest 파일 존재, SPA 404 일치 |

유지하는 소스에서 `.js`, `.jsx`, `.sass`, `.scss` 파일이 남아 있지 않은 것을 별도로 검사했습니다. 배포용 `.js`는 Vite가 생성합니다. npm 잠금 파일은 현재 의존성과 일치합니다.

기존 이력서의 프로젝트 16개 모두 제목·기간·업무·기술이 보존된 것을 비교했습니다. 학력 3개와 회사 경력 4개도 유지했습니다.
